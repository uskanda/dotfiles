# developブランチに切り替えて最新の状態に更新

developブランチに切り替えて最新の状態に更新してください。

## 手順

1. **未コミットの変更を確認**
   - `git status` で未コミットの変更があるか確認
   - 未コミットの変更がある場合は**警告して処理を中止**

2. **developブランチに切り替え**
   - `git checkout develop` でブランチを切り替え

3. **最新の変更を取り込み**
   - `git pull` で最新のdevelopブランチの変更を取得

4. **結果確認**
   - `git log --oneline -5` で最新のコミットを表示

## 未コミットの変更がある場合

以下のように警告して、何も実行しないこと：

```
未コミットの変更があります。

変更されたファイル:
- [ファイル一覧]

先にコミットするか、stashしてから再度実行してください。
処理を中止しました。
```
