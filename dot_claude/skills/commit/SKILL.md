# 現在の変更内容をgitコミット

現在の変更内容をgitコミットしてください。

## コミットのルール

1. **コミットの分割**: 変更内容を意味のある単位で2〜5個程度に分割してコミットする
2. **コミットメッセージは日本語で記載する**
3. **コミットメッセージのフォーマット**:
   - 1行目: 実施内容の概要（簡潔に）
   - 2行目: 空行
   - 3行目以降: 詳細な説明（2〜5行程度）
4. /commitコマンドの直後に数字もしくは"#nnn"と#と数字からなる文字列があった場合、gitlab等のissue trackerの番号であるとみなし、各コミットメッセージのprefixにその文字列を付与（数字の場合は"#"をつける）すること。

## コミットメッセージの例

```
ユーザー認証機能を追加

- JWTトークンを使用した認証処理を実装
- ログイン/ログアウトのAPIエンドポイントを追加
- 認証ミドルウェアを作成し、保護されたルートに適用
```

## 手順

1. `git status` と `git diff` で変更内容を確認
2. 変更を意味のある単位でグループ化
3. 各グループごとに `git add` と `git commit` を実行
4. 最後に `git status` で結果を確認
