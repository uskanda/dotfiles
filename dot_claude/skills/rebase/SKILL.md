# ローカルブランチのコミット整理

現在のローカルブランチのコミットを整理してください。

## 目的

develop等の元ブランチから分岐して以降のコミットをすべてまとめ、1〜5個程度の意味のあるまとまったコミットに再編する。

## 手順

1. **現状確認**
   - `git branch` で現在のブランチを確認
   - `git log --oneline` で分岐以降のコミット一覧を確認
   - 元ブランチ（develop等）との分岐点を特定

2. **コミットの分析**
   - 分岐以降の全コミットの内容を確認
   - 論理的にまとめられる単位でグループ化を計画
   - 1〜5個程度のコミットになるよう整理方針を決定

3. **リベース実行**
   - `git rebase -i <分岐点>` でインタラクティブリベースを開始
   - squash/fixupを使ってコミットをまとめる
   - 各コミットメッセージを適切に編集

4. **コミットメッセージのフォーマット**（日本語）
   - 1行目: 実施内容の概要（簡潔に）
   - 2行目: 空行
   - 3行目以降: 詳細な説明（2〜5行程度）

5. **結果確認**
   - `git log --oneline` で整理後のコミット一覧を表示
   - 変更内容が失われていないか確認

## 注意事項

- リベース前に念のため現在の状態をバックアップブランチとして保存することを検討
- コンフリクトが発生した場合は慎重に解決
- 強制プッシュが必要になる場合はユーザーに確認を取る
