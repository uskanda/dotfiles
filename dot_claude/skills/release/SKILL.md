# リリースの作成

remoteのmainブランチからタグおよびリリースを作成してください。

## タグの命名規則（CalVer）

1. `git fetch --tags` でリモートのタグを取得する
2. `git tag -l` でタグ一覧を取得する
3. タグ形式は `vYY.MM.X`（例: `v26.04.1`）
   - `YY.MM` は現在の年月（JSTベース: `TZ=Asia/Tokyo date '+%y.%m'`）
   - `X` は当月のリリース連番（1始まり）
4. 当月のタグ（`vYY.MM.*`）の中から最大の `X` を取得し、+1 したものを新しい `X` とする
5. 当月のタグが存在しない場合は `X=1` とする

## リリースの作成

1. 直前のバージョンのタグを特定する（タグ一覧の最新のもの）
2. 取得したバージョンにreleaseが存在するか確認する。releaseがなければ以下3.から5.のタグとリリース作成を行う。対応するリリースがまだなければ、取得したバージョンのタグに対してrelease作成のみを行い、6.に進む
3. `git log --oneline <前回タグ>..origin/main` で差分コミットを取得する
4. 差分コミットから説明文を作成する:
   - 利用者にわかる粒度で、改修した機能を1機能1行で記載する
   - コミットメッセージに `#YYY`（issue番号）が含まれる場合、行頭に `#YYY` をつける
   - Mergeコミットやフォーマット修正など利用者に関係のない変更は省略する
5. 以下のコマンドでタグとリリースを作成する:
   ```
   glab release create <タグ名> \
     --ref main \
     --name "<タグ名>" \
     --notes "<生成した説明文>"
   ```
6. 作成されたリリースのURLを出力する
